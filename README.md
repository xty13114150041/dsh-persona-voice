# dsh-persona-voice

中文 | [English](README.en.md)

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）用的人设转述插件。

执行任务的 agent 专心干活，另一个带上下文的"人设 agent"负责把每一轮的最终回答改写成你设定的角色口吻。你在对话里看到的是人设版回答，原文折叠在思考过程里，随时可以展开核对。

## 效果

- 启用后，执行 agent 的回答直接折叠进过程链，不会先露出原文再消失；过程里显示"正在组织语言…"，几秒后出现人设版。
- 回答下方有"查看原文"按钮，可在人设版和原文之间切换；原文同时以"【执行原文】"的形式放进思考过程。
- 只改写每轮的最终回答；工具调用、中间步骤、子 agent 不受影响。
- 人设 agent 有自己的多轮上下文：用户的话、执行 agent 的原文、它自己说过的话。所以它记得前面聊过什么，也不容易每次都用同样的结尾。

## 工作方式

```
用户 ──► 执行 agent（A）──► 最终回答（原文）
                                │
                                ▼
           人设 agent（B）：人设 + 转述规则 + 多轮历史
                                │
                                ▼
              界面显示人设版，原文折叠进思考过程
```

- 宿主端监听 `agent/turn-stopping`，在后台单独调用一次模型。这次调用不带工具，也不进入 A 的上下文。
- B 的上下文按"用户的话 + A 的原文 → B 的回答"逐轮拼接，只往后追加；超过上限时一次删掉最早的一半，人设固定在 system。这样大多数轮次的前缀不变，便于命中提示缓存。
- 每条用户消息末尾附一句固定的简短提醒，防止长对话里人设走样；文本固定，不影响缓存。
- 每轮的实际用量（含缓存命中）记在 `debug.log`。
- 浏览器端包装官方的助手消息渲染器，只替换最终回答的内容，依旧由官方组件渲染 Markdown。
- 默认转述规则要求 B 只转述，不新增行动；代码、路径、数字、错误信息原样保留。

## 安装

目前只能从源码安装：

```bash
git clone https://github.com/xty13114150041/dsh-persona-voice.git
```

在 DSH profile 目录（桌面版为 `~/.dsh/profiles/desktop`）的 `package.json` 中：

```jsonc
{
  "dsh": { "profile": { "bundles": [ /* …原有内容… */, "@local/dsh-persona-voice" ] } },
  "dependencies": { /* …原有内容… */, "@local/dsh-persona-voice": "link:/你的路径/dsh-persona-voice" }
}
```

然后在该目录运行 `pnpm install`，再重启 DSH。修改前建议先备份 `package.json` 和 `pnpm-lock.yaml`。

## 设置

在 DSH **设置 → 人设转述** 中设置。保存后下一轮就会生效，不需要重启。

| 设置 | 说明 |
|---|---|
| 启用人设转述 | 默认关闭 |
| 转述用的模型 | 默认跟随当前会话的模型；列表与输入框的模型菜单一致，读取一次后缓存，可点“刷新模型列表”更新 |
| 思考强度 | 默认自动（能关就关，否则最低档）；指定模型后可选该模型支持的任一档 |
| 人设预设 | 可以保存多个人设，用下拉框切换；下拉框选中的就是正在使用的人设。可以新建、改名、删除 |
| 人设文件 | 每个预设可选。填写后每轮从文件读取人设；文件中有 `<xxx_persona>…</xxx_persona>` 块时只取这一块 |
| 人设提示词 | 每个预设不使用人设文件时，直接在这里粘贴人设 |
| 转述规则 | 附加在人设后面的转述约束，可以恢复为默认规则 |
| 每轮提醒 | 附在每条用户消息末尾的固定提醒；留空则不加 |
| 最多记忆轮数 / 输出上限 | 控制 B 的上下文长度和输出长度 |

数据存放在 `~/.dsh/persona-voice/`：

- `settings.json`：设置
- `<会话 id>.json`：每轮的原文和人设版
- `debug.log`：调试日志

## 注意事项

- 每轮都会多一次模型调用，会产生额外的 token 费用。
- 人设版由模型改写，有改错信息的风险。重要内容请展开原文核对。
- 复制、引用按钮拿到的仍是原文。
- 执行 agent 看不到人设版。如果人设版里出现了原文没有的内容，执行 agent 是不知道的。默认规则禁止 B 新增行动，就是为了避免这种情况。
- 浏览器端的做法是包装官方渲染器，依赖 DSH 内部结构。DSH 升级后可能失效；失效时会退回显示原文。
- 已在 DSH Desktop 0.2.2-rc.2（macOS）上测试。要求 DSH 0.2.2-rc.2 及以上：rc.2 起同一条回答会按"思考/正文"拆成两行渲染，本插件按这个结构只挂一次按钮。
