# dsh-persona-voice

中文 | [English](README.en.md)

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）用的人设转述插件。

执行任务的 agent 专心干活，另一个带上下文的"人设 agent"负责把每一轮的最终回答改写成你设定的角色口吻。你在对话里看到的是人设版回答，原文折叠在思考过程里，随时可以展开核对。

## 效果

- 启用后，执行 agent 的回答直接折叠进过程链，不会先露出原文再消失；过程里显示"正在组织语言…"，几秒后出现人设版。
- 回答下方有"查看原文"按钮，可在人设版和原文之间切换；原文同时以"【执行原文】"的形式放进思考过程。
- 只改写每轮的最终回答；工具调用、中间步骤、子 agent 不受影响。
- 人设 agent 有自己的多轮上下文：用户的话、执行 agent 的原文、它自己说过的话。所以它记得前面聊过什么，也不容易每次都用同样的结尾。

## 工作方式

```
用户 ──► 执行 agent（A）──► 最终回答（原文）
                                │
                                ▼
           人设 agent（B）：人设 + 转述规则 + 多轮历史
                                │
                                ▼
              界面显示人设版，原文折叠进思考过程
```

- 宿主端在 `agent/turn-stopping` 固定本轮的问答，再在后台调用转述模型。自动续轮没有新用户消息时，不补入上一轮提问。这次调用不带工具，也不进入 A 的上下文。
- B 的上下文按「用户的话 + A 的原文 → B 的回答」拼接，人设固定在 system。可选仅本轮、近 5 轮（含本轮）或全部已有转述历史。「全部对话」只往后追加，比较容易维持相同前缀；「近 5 轮」按轮次滚动截取。
- 每条用户消息末尾附一句固定的简短提醒，防止长对话里人设走样；文本固定，不影响缓存。
- 每轮的实际用量（含缓存命中）记在 `debug.log`。
- 浏览器端包装官方的助手消息渲染器，只替换最终回答的内容，依旧由官方组件渲染 Markdown。
- 默认转述规则要求 B 只转述，不新增行动；代码、路径、数字、错误信息原样保留。

## 安装

**桌面版：** 打开 DSH 的「插件 → 添加插件」，粘贴 [GitHub Release 安装包](https://github.com/xty13114150041/dsh-persona-voice/releases/download/v0.6.0/dsh-persona-voice.tgz) 的地址，按提示确认。也可以先下载 `.tgz`，再选择本地安装包。

**Web / CLI：**

```bash
dsh plugin --profile web add https://github.com/xty13114150041/dsh-persona-voice/releases/download/v0.6.0/dsh-persona-voice.tgz
```

如果用的是自定义 profile，把 `web` 换成对应名称。安装包是可直接运行的 JavaScript，不需要构建或授权安装脚本。安装后按 DSH 提示刷新或重启；本插件默认关闭，在「设置 → 人设转述」设置角色并开启。已经通过本地链接安装的用户，请先从同一 profile 移除旧链接，再安装发行版；插件设置和历史保留。

卸载可用 DSH「插件」页，或运行 `dsh plugin --profile web remove @local/dsh-persona-voice`。卸载不会删除本地数据。

## 设置

在 DSH **设置 → 人设转述** 中设置。保存后下一轮就会生效，不需要重启。

| 设置 | 说明 |
|---|---|
| 启用人设转述 | 默认关闭 |
| 转述用的模型 | 默认跟随当前会话的模型；列表与输入框的模型菜单一致，读取一次后缓存，可点“刷新模型列表”更新 |
| 思考强度 | 默认自动（能关就关，否则最低档）；指定模型后可选该模型支持的任一档 |
| 人设预设 | 可以保存多个人设，用下拉框切换；下拉框选中的就是正在使用的人设。可以新建、改名、删除 |
| 人设文件 | 每个预设可选。填写后每轮从文件读取人设；文件中有 `<xxx_persona>…</xxx_persona>` 块时只取这一块 |
| 人设提示词 | 每个预设不使用人设文件时，直接在这里粘贴人设 |
| 转述规则 | 附加在人设后面的转述约束，可以恢复为默认规则 |
| 每轮提醒 | 附在每条用户消息末尾的固定提醒；留空则不加 |
| 转述上下文 | 仅本轮、近 5 轮（本轮 + 最多 4 轮旧内容）或全部已有转述记录；新设置默认近 5 轮，已有轮数上限在主动切换前保持不变 |
| 输出上限 | 控制 B 的回答长度 |

**转述费用估算**显示今日（主机时区）和本地日志累计，只算 B 的额外调用。展开「模型单价」，选择要计价的渠道和模型，填写币种和四项每百万 Token 的价格，再单独点「保存单价」。不收费或不适用的项填 0；缺少单价或用量的调用不计入金额。改价会重算历史用量，不同币种分开显示。即使用官方 API 价作参考，结果也不等于渠道实际扣费。

转述规则、每轮提醒和输出上限收在「高级设置」里。

## 数据与隐私

启用后，插件用 DSH 已配置的模型渠道做转述。所选模型会收到人设、本轮用户文字、执行 agent 的最终回复，以及你允许带入的历史转述文本。若配置了人设文件，DSH 宿主会读取指定文件，并把其中用于人设的内容随请求发给该模型。不要把密钥或不想发送给模型服务商的内容放进人设或对话。插件不需要另外提供 API 密钥。

插件数据保存在 `$DSH_HOME/persona-voice/`（默认 `~/.dsh/persona-voice/`）；关闭插件不会删除历史：

- `settings.json`：设置
- `rates.json`：手动填写的模型单价
- `<会话 id>.json`：每轮的原文和人设版
- `debug.log`：调试日志

## 注意事项

- 每轮都会多一次模型调用，会产生额外的 Token 费用。会话很长时，「全部对话」可能增加费用或超过模型的上下文上限。
- 人设版由模型改写，有改错信息的风险。重要内容请展开原文核对。
- 复制、引用按钮拿到的仍是原文。
- 执行 agent 看不到人设版。如果人设版里出现了原文没有的内容，执行 agent 是不知道的。默认规则禁止 B 新增行动，就是为了避免这种情况。
- 浏览器端的做法是包装官方渲染器，依赖 DSH 内部结构。DSH 升级后可能失效；失效时会退回显示原文。
- 声明支持 DSH `^0.2.2-rc.2`。旧版曾在 DSH Desktop 0.2.2-rc.3（macOS）上测试；0.6.0 已在隔离的 DSH Web 0.2.2-rc.5 配置中验证安装、设置接口、浏览器模块和卸载。Desktop 界面未复测。
